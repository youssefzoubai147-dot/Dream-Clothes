# متجر ملابس حقيقي — Arabic RTL

هذا المشروع ليس صفحة HTML تجريبية فقط. يحتوي على:
- متجر عام متجاوب مع الهاتف.
- المنتجات + الصور + السعر + الفئة + المقاسات + الألوان + المخزون.
- سلة مشتريات.
- طلب حقيقي يُحفظ في PostgreSQL.
- الدفع عند الاستلام.
- لوحة إدارة محمية بتسجيل دخول.
- إضافة / تعديل / حذف المنتجات.
- رؤية الطلبات وتغيير حالتها.
- إرسال رسالة للعميل تظهر في صفحة تتبع الطلب.
- زر واتساب للرد على العميل.
- صفحة تتبع الطلب برقم الطلب والهاتف.

## التشغيل محلياً

1. ثبّت Node.js 20+ وPostgreSQL.
2. أنشئ قاعدة بيانات باسم `clothing_store`.
3. انسخ `.env.example` إلى `.env`.
4. ضع بيانات PostgreSQL وكلمة مرور الإدارة في `.env`.
5. نفّذ:
   `npm install`
   `npm start`
6. افتح:
   `http://localhost:3000`
   ولوحة الإدارة:
   `http://localhost:3000/admin`

## النشر العام

المشروع مصمم ليُرفع كـ Node/Express Web Service مع PostgreSQL.
على Render مثلاً:
- Web Service: Build Command = `npm install`
- Start Command = `npm start`
- أضف متغيرات البيئة الموجودة في `.env.example`.
- أنشئ Render Postgres وضع `DATABASE_URL` في الخدمة.

بعدها تحصل على رابط عام، ويمكن ربط Domain مخصص من إعدادات الاستضافة.

## مهم قبل البيع الحقيقي

غيّر `ADMIN_EMAIL` و`ADMIN_PASSWORD` و`JWT_SECRET` فوراً.
أضف سياسة الخصوصية وشروط البيع ومعلومات الإرجاع والشحن.
لصور المنتجات في بيئة إنتاج، استخدم تخزيناً دائماً للصور أو خدمة Object Storage؛ لا تعتمد على ملفات محلية في استضافة ذات نظام ملفات مؤقت.
الدفع الحالي هو الدفع عند الاستلام. يمكن إضافة بوابة دفع لاحقاً.
